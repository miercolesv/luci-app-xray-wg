luci-app-xray-wg

An apk repository for OpenWrt. WireGuard carried inside an xray VMess transport, configured from LuCI.

Read this first. The tunnel itself was tested end to end against a real server, but never on OpenWrt hardware. A signature proves a package came from this project's key — not that the software is correct or safe. Obfuscation hides VPN use from your network and ISP, not from the sites you visit.

Add the repository

The package is noarch, so this one repository serves every router. Needs OpenWrt 24.10+ using apk.

wget -O /etc/apk/keys/xray-wg-repo.pub.pem \
  https://miercolesv.github.io/luci-app-xray-wg/xray-wg-repo.pub.pem

echo "https://miercolesv.github.io/luci-app-xray-wg/packages.adb" \
  >> /etc/apk/repositories.d/customfeeds.list

apk update
apk add luci-app-xray-wg

Or install a single file, no shell

Download the .apk from Releases and upload it under System → Software in LuCI. Adding the repository above is only worth it if you want apk update to offer upgrades.

Verify the key

openssl rsa -pubin -in /etc/apk/keys/xray-wg-repo.pub.pem \
  -outform DER | sha256sum

Compare against the fingerprint printed in the repository's keys/README.md.

Then

Open VPN → Xray WireGuard in LuCI. For your own server, pick the Self-hosted / manual profile and fill in the fields — the self-hosting guide covers the server side. Then paste a wg-quick config and press Connect. Nothing else needs a shell.
